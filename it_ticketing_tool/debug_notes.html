Open browser console and navigate to a ticket detail page to see debug logs.

Look for these console messages:

  • "TicketUpdatesSection - isSupportUser: [true/false]"
  • "Notes tab clicked, isSupportUser: [true/false]"
  • "Rendering NotesTab, activeTab: notes"
  • "NotesTab: ticket data: [object]"

User Role Check

  • admin
  • super_admin
